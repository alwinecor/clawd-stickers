# 01 · Dev Life · 程序员日常

20 animated stickers about a programmer's everyday life, starring Clawd. Clawd's eyes are two small black squares (sometimes squinting into ^ ^ or > <), and there's no mouth: every joke is told through movement and props. These rules follow [01-movie-night](https://github.com/Qisi3344/clawd-moji/tree/main/01-movie-night) from Qisi3344/clawd-moji.

> 程序员日常主题，20 个动态表情，Clawd 主演。眼睛是两个小黑方块（偶尔眯成 ^ ^ 或 > <），不画嘴，戏全靠动作和道具。这套规矩沿用 Qisi3344/clawd-moji 的 01-movie-night。

## Download / Use in WeChat · 下载 / 在微信里用

- `gif/`: full size, 276×288, transparent background
- `wechat/`: 240×240, ≤100KB each, transparent background (a few longer ones drop frames to fit)

To use them in WeChat, send a GIF from `wechat/` to "File Transfer", open it, long-press, and choose "Add to Stickers".

> - `gif/`：原尺寸 276×288，透明背景
> - `wechat/`：240×240、每张 ≤100KB，透明背景（个别帧数多的做了抽帧）
>
> 在微信里用：把 `wechat/` 里的 GIF 发到「文件传输助手」，点开长按 →「添加到表情」。

## Build it yourself · 自己生成

```bash
cd src
pip install pillow
python clawd_dev.py            # all 20 / 全部 20 个
python clawd_dev.py compact    # just one / 只生成一个
```

No extra font is needed: the command-line text uses a tiny 3×5 pixel font built into the script.

> 不需要额外字体，命令行文字用的是代码里自带的 3×5 小像素字。
